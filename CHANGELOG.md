# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2025-11-07

### Changed
- Updated Laravel Nova compatibility to support both 4.x and 5.x
- Updated minimum PHP requirement to 8.1 for Nova 5 compatibility

## [1.0.0] - 2025-11-07

### Added
- Initial release
- Customizable breadcrumb navigation card for Laravel Nova
- Support for hierarchical breadcrumb structures
- Fluent API for building breadcrumbs
- Optional home icon for first breadcrumb item
- Customizable separator character
- Dark mode support
- Responsive design
- Compatible with Laravel Nova 4 & 5
